# nekobits

Open-source firmware and on-device AI for low-power IoT devices.
Private by design, offline-first, built to help people.

## What this is

A collection of open-source projects, maintained by one software architect in Italy.
Not a company. No telemetry, no cloud requirement.

## Focus

- On-device AI on ESP32-S3 / ESP32-P4
- E-ink interfaces for high legibility
- LoRa mesh messaging and positioning where phones have no signal

## Who is behind it

nekobits is designed and maintained by Luca Nardelli, software architect
with 24 years of experience ([LinkedIn](https://www.linkedin.com/in/luca-nardelli/)).

## How AI is used

AI coding tools are used as instruments, not as authors. The maintainer
defines the architecture, the design patterns and the features, then
reviews and tests every change. Responsibility for the code stays human.
Each repository states its own licence.

## Contributing

The projects are open source but not collaborative: pull requests are not
accepted. Bug reports and ideas are welcome via issues.

See [how to contribute](https://github.com/nekobits-org/.github/blob/main/CONTRIBUTING.md)
and the [security policy](https://github.com/nekobits-org/.github/blob/main/SECURITY.md).
