# Security policy

## Reporting a vulnerability

Do not open a public issue for a security problem.

Write to info@nekobits.it with:

- the repository and the version or commit affected;
- the hardware involved, if any;
- a description of the problem and the steps to reproduce it.

You will get an answer within 14 days. nekobits is maintained by one person,
so fixes are scheduled by severity; you will be told what to expect.

Please allow time for a fix before publishing details.

## Supported versions

Only the latest release of each project receives security fixes.

## Scope

The projects are research and development software, provided without
warranty under their licences. They are not certified for safety-critical use.
