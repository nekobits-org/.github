# Contributing

nekobits is a collection of open-source projects written and maintained by one
person. The code is open to read, use and fork under each repository's licence,
but the projects are not collaborative.

## What is welcome

- Bug reports, with the steps to reproduce them and the hardware you used.
- Ideas and feature requests.
- Reports from real use: what worked, what did not, on which device.

Open an issue in the repository concerned.

## What is not accepted

- Pull requests. They are closed without review, so that the maintainer stays
  the single author of the code.
- Code pasted into issues with a request to merge it.

If you need a change, describe the problem in an issue. If you need it now,
fork the repository: the licence allows it.
